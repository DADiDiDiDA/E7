# E7 · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。
> 模拟器仅在 Mumu 模拟器上测试过。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **🎮 进入游戏**：启动并进入游戏
- **🌿 圣域精灵之森照料**：进入圣域照料精灵之森（点击企鹅/泉水/植物/照料）
- **📧 邮件奖励领取**：领取邮箱内所有奖励
- **🛒 商店购买每日物品**：只买每日免费礼包
- **⚔️ 刷体力**：可自定义选择要刷取的讨伐副本；只刷地狱级难度！！！！
- **🏟️ 竞技场10次**：只刷人机竞技场，快速战斗次数和挑战次数不足时会退出
- **⚔️ 骑士团签到并请求资源**：只会请求经验精灵，不会赠送资源欧
- **🎁 领取活跃度奖励**：只会领取活跃度100时的奖励，未到100不会领取
- **🎪 活动奖励处理**：自动检测并领取活动界面中的可领取奖励（周年每日20抽、xx日记、免费召唤使用、xx之路日常领取等，每项可单独开关）
- **⏹️ 退出游戏**：其实没必要，直接使用设置里的"任务完成后退出"即可

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
